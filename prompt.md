# Prompt

**Type your prompt below the line, save, then say `go` in the session.**

Nothing in this file is an instruction until then. The AI assistant reads it when you say `go` —
or `run the prompt`, or the like — and at no other time; a half-written thought sitting here is
not a request, however finished it looks. Once the prompt has run it is moved verbatim into
`_prompt/unfiled.md` and this file is cleared back to this marker, so it is empty whenever
nothing is waiting.

You can also just type in the session instead. Either way the round is filed for you; what
the project *is* belongs in `CLAUDE.md`, and the prompt history lives in `_prompt/`.
