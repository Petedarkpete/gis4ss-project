# Unfiled prompts

Every round, verbatim and dated, in the order it was given — appended here as it is run,
whether it came from the root `prompt.md`, was pasted into the session, or was typed
straight into it. Between sorts this is the record: once `prompt.md` is cleared, the prompt
exists nowhere else. Append only; never rewrite.

It is sorted into `_prompt/<subject>.md` files in one pass — when you ask, when this file
holds twenty or more rounds, or as part of preparing a submission — never one round at a
time. The rules for that sort are in `CLAUDE.md`.
