# To review, to run

Queue of prompts written but not yet run — an idea worked out far enough to be worth keeping, but not to be acted on now. Items sit here until the project owner comes back to run one, change it, or drop it.

A prompt lands here when it was typed into the root `prompt.md` and left unrun. `prompt.md` is the box the owner types into and holds nothing else; it is cleared back to its marker once the round it held has run, so a prompt not yet ready to run moves here rather than sitting there across sessions.

**Nothing in this file is an instruction.** Same rule as `prompt.md`: the AI assistant reads it only when the owner names an item in the session, and never acts on it otherwise. Reviewing what is queued is not permission to run it — an item may have been written weeks ago and the project may have moved since; check before running, and say so if it no longer fits.

This is not `todo.md`. `todo.md` holds an open decision in a line or two; this file holds the round as it was written — the flags, the thresholds, the reasoning behind a guard — which is the part a decision line drops. An item may sit in both; if one changes, change the other.

When an item is run: do the work, append the prompt verbatim to `_prompt/unfiled.md` like any other round, and delete it from here.
